🎬 Admin Bioskop

Film yang ditambahkan di sini muncul di bioskop game. Perubahan disimpan langsung ke repo purwoadhii/Liburan dan tampil di game sekitar 1–2 menit kemudian.

Buat token fine-grained di GitHub → Settings → Developer settings → Personal access tokens, khusus repo Liburan, izin Contents: Read and write. Token hanya disimpan di browser ini.

Ada 3 tempat film. Isi judulnya, lalu tekan Simpan film di masing-masing kotak. Video dan poster boleh menyusul.
